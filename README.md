# HR Employee Attrition Prediction Using Machine Learning

## Project Overview

This project uses Machine Learning to predict employee attrition and identify factors associated with employees leaving an organization.

The project analyzes employee information and develops classification models to support HR analytics and employee retention strategies.

## Dataset Information

- Dataset: IBM HR Analytics Employee Attrition & Performance
- Total Records: 1,470
- Original Features: 35
- Target Variable: Attrition
- No Attrition: 1,233 employees
- Attrition: 237 employees

## Project Objectives

1. Analyze employee data using Exploratory Data Analysis (EDA).
2. Clean and preprocess the dataset.
3. Identify factors associated with employee attrition.
4. Train and compare five Machine Learning classification models.
5. Evaluate models using Accuracy, Precision, Recall and F1 Score.
6. Identify important features using Random Forest.

## Machine Learning Models

1. Logistic Regression
2. Decision Tree
3. K-Nearest Neighbors (KNN)

## How to Run the Project

1. Clone this repository.
2. Install the required libraries:

   `pip install -r requirements.txt`

3. Keep the dataset in the project folder.
4. Run the Python file:

   `python HR_Employee_Attrition.py`
